# DGS Note Book

## Amaç
Video transkriptlerini temel alarak DGS odaklı, tekrar dostu notlar oluşturmak.

## Çalışma İlkeleri
- Konu sırası `Dgs ders konuları.txt` dosyasına sadık kalınır.
- Videolar ana bağlamdır.
- Eksik bilgiler DGS kapsamı dışına çıkmadan tamamlanır.
- Her konu aynı şablonu kullanır.
- Her not sonunda **Hızlı Tekrar** bulunur.
- Notlar video özeti değil, bağımsız çalışma kaynağıdır.

## Konu Şablonu
1. Amaç
2. Temel Bilgiler
3. Kurallar
4. DGS Püf Noktaları
5. Tuzaklar
6. Ek Bilgiler
7. Örnek
8. Hızlı Tekrar
9. Değişiklik Geçmişi
