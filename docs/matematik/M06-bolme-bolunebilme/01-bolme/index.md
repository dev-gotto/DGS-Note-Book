# bölme

## Amaç

Bölme işleminin elemanlarını (bölünen, bölen, bölüm, kalan), bölmenin sağlaması özdeşliğini ($A = B \times C + K$) ve "bölen > kalan" kuralını öğrenerek harfli/bilinmeyenli bölme sorularını çözebilmeyi; ayrıca "bölme yapmadan kalan bulma" ilkesiyle sayı yerine kalan kullanarak işlem yapmayı hedefler.
