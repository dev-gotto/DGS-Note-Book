# Hızlı Tekrar — İşlem Yeteneği

- Aynı işaret → topla, işareti koru. Farklı işaret → çıkar, büyüğün
  işaretini koru.
- Aynı işaretli çarpım/bölüm → pozitif; farklı işaretli → negatif.
- Parantez önü **eksi** → tüm işaretler değişir. **Artı** → değişmez.
- İşlem sırası: **Parantez → Üs → (Çarpma/Bölme, soldan sağa) →
  (Toplama/Çıkarma, soldan sağa)**
- Çarpma-bölme arasında, toplama-çıkarma arasında **öncelik yoktur.**
- Çift kuvvet eksiyi artıya çevirir **yalnızca taban parantez içindeyse.**
- `a⁰ = 1` (a≠0) · `1ⁿ = 1` · `(-1)^çift = 1` · `(-1)^tek = -1`
- Harf yerine (özellikle negatif) sayı koyarken **mutlaka parantez kullan.**
- Kutu/sembol sorularında büyük sayıdan başlayıp sistematik eleme yap.
